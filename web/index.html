Qualitative activity based on verified periods and density, not mathematical entropy. The scale is the same for all frames; these settings do not alter cells.

Saturation only affects the image. Empty blocks are always black. Live-cell counts remain exact.

Remote access token

Stored only in this tab. Excluded from the configuration file.

Fields marked “Live” can be applied to a running server. Fields marked “Restart” prepare the next startup. API changes do not write config.toml to disk. The config contains no live cells: save the state separately.

To persist settings, save the downloaded file and start the server with --config config.toml. Your draft stays here until you reset it.
